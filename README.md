# TILEFORM Studio

**v1.5.1** · [アプリを開く](https://ecleaire.github.io/tileform-studio/)

縦と横のマス数を指定するだけで、3種類のSTLパーツを自動配置し、3Dプリント用のタイルを作成できるWebアプリです。インストール不要で、PC・スマートフォンから利用できます。

### v1.5.1：更新履歴ページ

「使い方」の一番下から、[バージョンアップ履歴](https://ecleaire.github.io/tileform-studio/changelog.html)を開けます。各バージョンの日時（日本時間）と主な変更を掲載しています。同じページに「今後のアップデート予定」（1×1・1×2、床の非表示、テクニックパーツ、操作性、UI）も掲載しています。今後の更新時には、このページにも日時・変更内容を追記します。

### v1.5.0：大きい文字と凹凸強調表示

補助説明や単位も含め、文字サイズの下限を14px、本文を16pxに引き上げました。入力プリセットを別の行へ配置し、大きな文字で操作できるようにしています。320px幅と390px幅のスマートフォンでも、文字・モデル・操作部品の見切れを検証します。

「見え方を変える」の「凹凸をくっきり表示」は初期ONです。くぼみや段差の明暗を強める表示用の着色で、STLデータの形状や寸法は変えません。好みに応じてOFFにでき、選択は保存されます。初期設定に戻すとONになります。

### タイルを大きく表示し、操作部品を強調

床全体ではなく、タイル本体に合わせて表示倍率を調整します。画面幅・視点を変えたときも自動で合わせ直します。選択中の視点を濃い背景と白文字で区別し、ズーム・全体表示の操作部品を拡大しました。

スマートフォンでは操作部品を横並びでモデルの上に置き、寸法ラベルは横・縦を明記して下部へ分離しています。フィット時のモデルの見切れ・操作部品との重なり・表示サイズを自動テストでも確認します。

### 文字・モデルの視認性と最大サイズ判定

小さい文字を拡大し、説明文と寸法ラベルの色を濃くしました。初期グレーを少し濃い色に変更し、旧初期グレーを保存済みの場合も移行します。自分で設定した別の色は保持します。スマートフォンのパーツ内訳は、展開時に読みやすい縦並びになります。

「最大サイズ」は選択モデルの実寸で計算します。例：横31.8 × 縦47.8 mmの床なら、v3は縦6 × 横4マス、v2は縦5 × 横3マスです。表示する収容数も上限32マスと実寸に合わせました。

### v3／v2モデル切り替え

初期設定はv3です。「モデルを選ぶ」を開くとv2／v3を切り替えられます。v3では角・端は外側のみ0.1 mm削った角v3.1・端v3、中はv2を使用します。v2を選ぶと角・端もv2になります。選択はブラウザに保存され、「初期設定に戻す」でv3に戻ります。元STLは伸縮・再保存せず、そのまま同梱しています。角の上側の接合位置を基準に配置し、削った外周を内側に寄せないようにしています。

| 提供ファイル | 同梱ファイル | 寸法（mm） | 三角形数 |
| --- | --- | --- | --- |
| 角v3.1.stl | `dist/assets/corner.stl` | 7.9 × 7.9 × 3.12 | 318 |
| 端v3.stl | `dist/assets/edge.stl` | 7.9 × 8 × 3.12 | 528 |
| 中v2.stl | `dist/assets/center.stl` | 8 × 8 × 3.15 | 1,004 |

配置ピッチは8 mmのままです。外周は両側で合計0.2 mm小さくなり、v3の完成品の各方向の外寸は **マス数 × 8 − 0.2 mm** です。2×4なら横31.8 × 縦15.8 mm、4×3なら横23.8 × 縦31.8 mmになります。画面の寸法線・仕上がり寸法・出力ファイル名も実際の外寸を示します。v2の外寸はマス数×8 mmのままで、2×4なら横32 × 縦16 mmです。出力ファイル名には選択したモデルも含めます。床の8 mmグリッドは配置の目安です。

STLの読み込みURLも更新し、旧モデルのキャッシュとの混在を防いでいます。このモデル構成での実プリント・嵌合は未確認です。小さいサイズで試し刷りして確認してください。

真上からもくぼみ・段差を確認できるよう、プレビューに輪郭線を表示します。輪郭線はSTLには含まれません。

## 主な機能

- **自動配置**：角・端・中のパーツを位置に合わせて配置・回転
- **3Dプレビュー**：回転・拡大縮小、構造面・フラット面の切り替え
- **表示設定**：モデルの色変更、パーツの色分け・分解表示
- **造形範囲の確認**：プリンターのプリセット、またはサイズを手動指定。「最大サイズ」で収まるマス数を一括設定
- **STL出力**：各パーツを結合し、ひとつの立体としてダウンロード。段階別の進捗表示・キャンセルに対応
- **設定の保存**：サイズ・モデル・単色・色分け・プリンターと床サイズを、このブラウザに自動保存

## 使い方

1. [アプリ](https://ecleaire.github.io/tileform-studio/)を開き、**縦 × 横**のマス数を入力します。
2. 3Dプレビューで形状や配置を確認します。
3. **「STLをダウンロード」**を押し、スライサーでmm単位として読み込みます。

※ 造形範囲やモデルの色・表示方法は、見出しを開いて変更できます。プレビュー操作とSTL生成はブラウザの自動テストで確認しています。

### 最大サイズ・設定保存

「造形範囲を決める」を開き「造形範囲に収まる最大サイズにする」を押すと、選択したモデルの実寸で収まるマス数を計算し、上限32マスまで設定します。A1 miniの180 × 180 mmなら22 × 22マス（配置範囲176 × 176 mm／完成品175.8 × 175.8 mm）です。ブリムや除外領域の分は、床サイズを手動で小さくして調整してください。

有効なサイズ・色・プリンター設定はブラウザ内に保存し、次回起動時に復元します。「初期設定に戻す」でリセットできます。別端末との同期は行いません。保存が使えないブラウザや保存データが壊れた場合も、初期設定で操作を続けられます。視点や分解表示は保存しません。「初期設定に戻す」では、分解表示を解除し、3Dの初期視点に戻します。

### 出力の進捗とキャンセル

計算エンジンの準備、パーツ配置、結合、形状検証、STL作成の各段階を表示します。割合は処理段階の目安で、残り時間の予測ではありません。結合などの計算中は数値がしばらく止まる場合があります。「キャンセル」で計算を停止し、ダウンロードせずにサイズ変更・再出力できます。

## 仕様

| 項目 | 内容 |
| --- | --- |
| モデル | v3（初期設定）／v2を選択可能。中パーツは共通 |
| 入力範囲 | 縦・横それぞれ2〜32マス |
| 配置ピッチ | 8 × 8 mm（外周は各辺0.1 mm内側） |
| パーツ | 角・端・中の3種類 |
| 厚さ | 角・端：3.12 mm／中：3.15 mm |
| 初期設定 | 縦2 × 横4マス（外寸31.8 × 15.8 mm） |
| 初期造形範囲 | 180 × 180 mm（Bambu Lab A1 mini） |
| 出力形式 | STL（mm想定・単一ソリッド） |

※ 中パーツを含まない場合、仕上がりの厚さは3.12 mmです。

一部のLEGO®ブロックとの組み合わせを確認しています。ただし、3Dプリンターの性能や印刷設定、使用素材によって仕上がりが異なるため、互換性や嵌合を保証するものではありません。

## 注意事項

- STLの処理はブラウザ内で完結し、モデルデータは外部サーバーに送信されません。
- STL出力時に接合部分を微調整します。印刷前にスライサーで形状・寸法を確認してください。
- [Three.js](https://threejs.org/)（MIT）と[Manifold](https://github.com/elalish/manifold)（Apache-2.0）を使用しています。元のSTLデータの権利は提供者に帰属します。
- LEGO®はLEGOグループの商標です。TILEFORM StudioはLEGOグループの承認・提携を受けていない非公式ツールです。

最新版では、STLも画面のプログラムと同じバージョンのURLで読み込み、古いモデルのキャッシュとの混在を防ぎます。形状検証では外周の壁の連続性と内側のくぼみの向きを確認し、ブラウザでも実際のプレビューモデルを検証しています。

## 公開後の自動確認

GitHub Pagesのデプロイ後、GitHub Actionsが実際の公開URLで自動確認します。公開バージョンとJS・CSS・STL・WASMの内容照合、プレビューの向き、最大サイズ設定、設定保存、進捗・キャンセル・再出力、出力STLの寸法を検証します。公開直後の反映待ちは最大3分です。確認が失敗した場合はワークフローを失敗として表示します。デプロイ済みのサイトを自動で旧版へ戻す処理は行いません。
