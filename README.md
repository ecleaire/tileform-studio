# TILEFORM Studio

縦 × 横を入力すると、角・端・中のSTLを回転・配置してタイルを作る、ブラウザで動く小さなCADです。

初期値は **縦4 × 横3**。添付された3つのSTL（各8 × 8 × 3.25 mm）を使い、外寸は横24 × 縦32 × 高さ3.25 mmになります。

## できること

- 縦・横それぞれ2〜32マスを指定
- 四隅に角、外周に端、内側に中を自動配置・回転
- 実際のSTLによる3Dプレビュー、回転・ズーム
- 構造面／フラット面の切り替え、色分け、分解表示
- Web Workerでブーリアン結合し、単一ソリッドのバイナリSTLを出力（mm単位）

## ローカル起動

Node.js 20以降で、依存パッケージのインストールは不要です。

```sh
node scripts/serve.mjs
```

http://127.0.0.1:4173 を開きます。ES Modules・Web Worker・WASMを利用するため、HTMLを直接ダブルクリックせずHTTPサーバーを使用してください。

## 検証

```sh
node scripts/verify.mjs
```

2×2、2×4、4×3、3×4、6×6、2×32、32×2について、パーツ数・出力外寸・単一ソリッド・STL再読み込み後の閉じた面と向きを検証します。不正な入力も検証します。

## 形状と接合

`dist/assets/` の `corner.stl`（角）、`edge.stl`（端）、`center.stl`（中）が原本です。原本の座標オフセットを除去し、90度単位で回転して8 mmピッチで配置します。

原本のごく小さい丸め差で線のみの接触が発生するため、STL出力時は各マスをXY方向に1.00025倍し、隣接パーツ間に **0.002 mmの重なり** を設けて結合します。最後に指定された外寸で切り揃えます。表面の形状は最大約0.001 mm補正されます。結合結果が単一ソリッドでなければダウンロードせずエラーを表示します。色分け・分解表示はSTLに影響しません。

1列用の原本がないため縦横2マス以上に対応します。STLは単位情報を持たないためスライサーではmmを指定してください。実プリントでの嵌合は未検証です。小さいサイズで試し刷りしてください。

## 配信

`dist/` はビルド不要の静的サイトです。GitHub ActionsのPagesワークフローを同梱しています。GitHubのSettings → PagesでSourceを **GitHub Actions** に設定すると、mainへのpushで公開されます。

アプリの計算はブラウザ内で完結します。STLを外部サーバーへアップロードしません。フォントのみGoogle Fontsから取得し、接続できない場合はシステムフォントへ切り替わります。
